# University-Student-Record-System
C++ object-oriented university record system with student and professor management, course registration, graduation tracking, operator overloading, file processing, student record storage and search, dynamic memory, polymorphism, and exception handling.

#Features:
Student and professor management
Course registration and enrollment
Graduation date tracking
Operator overloading
Student record file storage
Student search from files
Exception handling
Polymorphism and dynamic memory
